# Retail Analytics Capstone Project

Hi there 👋  
I’m Christine, an aspiring Data Analyst. This project showcases my work analyzing retail customer behavior and sales trends using Python, SQL, Excel, and Tableau.  

## Project Overview
The goal of this project was to explore retail data to uncover patterns in customer purchases, product performance, and overall sales trends. This includes:  
- Understanding customer demographics and spending habits  
- Identifying top-selling products and categories  
- Creating visual dashboards for actionable insights  

## Tools & Skills
- **Python:** pandas, matplotlib, seaborn  
- **SQL:** data extraction and aggregation  
- **Excel:** pivot tables, dashboards  
- **Tableau:** interactive visualizations and dashboards  
- Data Cleaning & Analysis, Data Visualization, Problem Solving

## Key Insights
- Most customers fall within a moderate income range, with a small number of high-income outliers  
- Customer spending is concentrated in a few key categories, particularly wine and meat products  
- Marketing campaign response rates were generally low across the customer base  
- Customers with a graduation-level education represent the largest segment and show the highest engagement  
- A significant portion of customers are between ages 50–60  
- Married and “together” customers demonstrate slightly higher campaign engagement

## Business Implications
These insights suggest opportunities to improve targeted marketing strategies, particularly by focusing on high-performing product categories and more engaged customer segments.
